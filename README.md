# JIRA

Pixel-perfect Jira frontend clone and question-to-code finder built with React, Vite, and Node/Express.

## Features
- **Pixel-perfect Jira UI**: Recreated layout, sidebar, tabs, cards, avatars, and navigation.
- **Question-to-Code Finder**: The "Find a space" search box automatically parses the internal Markdown question bank and copies matching code solutions to your clipboard.
- **Gemini AI Fallback**: Seamless fallback to Google Gemini when search queries fall below the confidence threshold.

## Getting Started

### 1. Server Setup
```bash
cd server
npm install
npm start
```

### 2. Client Setup
```bash
cd client
npm install
npm run dev
```
